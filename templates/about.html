What is {{ project.title }}?

{{ project.title }} is the interactive educational application developed for {{ project.academic_title }}. It makes Simple Cubic (SC), Body-Centred Cubic (BCC), Face-Centred Cubic (FCC) and Hexagonal Close-Packed (HCP) structures easier to understand by connecting 3D geometry with lattice parameters, coordination number, atomic packing factor, nearest-neighbour distance and effective atoms per cell.

The aim is to move beyond static textbook diagrams: students can rotate and inspect structures, compare unit cells with larger crystal regions, explore coordination shells and stacking, and try real-material parameters.

  • Interactive 3D
  • Four crystal structures
  • Physics-driven calculations
  • Real material presets

Python and NumPy provide the scientific calculations, Flask serves the application and API, and Three.js renders the interactive crystal geometry in the browser.

KaTeX renders mathematical relations, while pytest validates the scientific model and API.

The project is live as a website hosted on Render.

Connection to Previous Coursework

The project combines concepts and practical skills developed across several earlier courses in the B.Sc. Physics programme.

Introduction to Scientific Computing

Scientific-computing skills turn solid-state physics equations and geometry into executable numerical models. NumPy represents lattice vectors, converts fractional and Cartesian coordinates, and supports neighbour-distance, cell-volume and packing calculations checked by scientific tests.

Introduction to Python Programming

Python is the project's main scientific and backend language. Functions, modules, lists and dictionaries support reusable geometry helpers, input validation, JSON handling and application logic.

Data Visualization with Python

Visualization principles help turn numerical data into understandable representations through meaningful colors, legends, labels and property comparisons. Here these principles are applied in an interactive 3D web environment rendered by Three.js, rather than a Python plotting library.

Data Science with Python

The connection is structured scientific data handling and validation: organizing material-property records in materials.json, deriving values from source parameters and checking consistency across SC, BCC, FCC and HCP comparisons. This is not a machine-learning or large-data project.

Web Development with Python

Flask routes, Jinja templates and JSON API endpoints expose the scientific Python model to the browser while keeping backend and frontend separate. Flask also serves CSS, JavaScript and images for the responsive, multi-page interface.

Additional Technologies & AI Assistance

Technologies beyond the team's previous coursework—particularly JavaScript, Three.js and WebGL-based interactive 3D rendering, along with KaTeX, native fullscreen and stencil-buffer clipping caps—were implemented with assistance from OpenAI Codex.

Codex served as a development assistant for implementation, debugging and integration. Project requirements, the scientific model, testing and final verification were developed and reviewed as part of the project work; scientific results were checked rather than accepted solely from AI output.
